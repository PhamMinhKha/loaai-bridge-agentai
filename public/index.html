🤖 Voice Gateway — ESP32-S3 Test Bench

Trạng thái: idle · agent=… tts=…

Chọn Agent và TTS cho phiên web (áp dụng ngay, không cần restart server). Nút Setup Hermes API tự bật API_SERVER trên Hermes (cổng 8642), ghi token vào .env, rồi chọn agent Hermes.

Mô phỏng ESP32-S3 gửi audio stream (mic). Server decode → Whisper → Agent → TTS → audio về. Web dùng PCM để đơn giản; firmware thật gửi Opus (server hỗ trợ cả 2).

Mô phỏng ESP32-S3 gửi text (không cần mic). Server → Agent → TTS → audio về.

Hướng dẫn cấu hình firmware ESP32-S3 (xiaozhi-esp32) để kết nối với Voice Gateway này.

1. Địa chỉ kết nối (WebSocket)

ESP32 và PC phải cùng mạng LAN. Dùng IP của PC này (host đang chạy gateway):

Port mặc định 3000, đường dẫn /ws. Nếu gateway chạy port khác, sửa theo PORT trong .env.

2. Gửi hello khi khởi tạo kết nối

Firmware gửi JSON chào server ngay sau khi WebSocket mở:

{ "type": "hello", "version": 1, "device_id": "esp32-001", "token": "test", "transport": "websocket", "audio_params": { "format": "opus", "sample_rate": 16000, "channels": 1, "frame_duration": 60 } }

Server trả lời hello_ack kèm session_id. Từ lúc này ESP32 gửi binary Opus thô (v1, không header).

3. Gửi audio (Opus raw)

  • Mỗi frame WebSocket binary = 1 packet Opus (60ms @ 16kHz mono).
  • Server tự VAD: phát hiện tiếng → listening, im lặng SILENCE_MS=1200ms → tự chốt câu.
  • Nếu firmware đã cắt VAD cục bộ, gửi {"type":"audio_end"} để chốt ngay.

4. Nhận phản hồi từ Gateway

MessageÝ nghĩa
{"type":"state","state":"listening"}Đang nghe mic
{"type":"state","state":"processing"}Đang decode/xử lý audio
{"type":"transcript_partial","text":"..."}STT từng phần (nếu bật)
{"type":"transcript","text":"..."}STT cuối câu
{"type":"state","state":"thinking"}Agent đang suy nghĩ
{"type":"state","state":"speaking"}Đang phát TTS
{"type":"agent_message","text":"..."}Câu trả lời text
audio_start + binary WAV + audio_endAudio TTS để phát qua speaker

5. Tuỳ chọn .env (trên PC gateway)

STT_PROVIDER=whisper WHISPER_MODEL=medium TTS_PROVIDER=pyttsx3 # none | pyttsx3 | edge | google TTS_VOICE=vi-VN-HoaiMyNeural AGENT_PROVIDER=mock # mock | openclaw | hermes OPENCLAW_URL=http://127.0.0.1:18789 HERMES_URL=http://127.0.0.1:8642 LISTEN_MS=30000 # chờ có tiếng tối đa 30s SILENCE_MS=1200 # im lặng 1.2s -> chốt câu

6. Chạy gateway & flash

# PC (gateway): npm install node src/index.js # ESP32 connect: ws://<PC_IP>:3000/ws

Firmware tham khảo: github.com/78/xiaozhi-esp32 (board esp-vocat). Chỉ cần firmware tuân thủ protocol trên — gateway không cần code firmware.
