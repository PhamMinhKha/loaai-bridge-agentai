      Cấu hình ESP32-S3

      Firmware xiaozhi-esp32 kết nối Loa Ai Agent Bridge qua WebSocket. ESP32 chỉ nhận text (llm); TTS chỉ phát trên tab Giọng nói / Chat của app.

      1. Địa chỉ WebSocket

      Internet (Cloudflare Named Tunnel): wss://voice.yourdomain.com/ws — hostname cố định. Tắt WSS tự ký, giữ HOST=0.0.0.0 (LAN + tunnel), bật REQUIRE_DEVICE_TOKEN. Không dùng *.trycloudflare.com (đổi mỗi lần chạy).

      2. Hello message

      { "type": "hello", "version": 1, "device_id": "esp32-001", "token": "<DEVICE_TOKEN_SECRET>", "transport": "websocket", "audio_params": { "format": "opus", "sample_rate": 16000, "channels": 1, "frame_duration": 60 } }

      3. Audio Opus raw

      • Mỗi frame binary = 1 packet Opus (60ms @ 16kHz mono).
      • VAD tự động: im lặng SILENCE_MS=1200ms → chốt câu.
      • Gửi {"type":"audio_end"} để chốt ngay.

      4. Protocol messages

      MessageÝ nghĩa
      state: listeningĐang nghe
      stt / transcriptKết quả STT
      llm / agent_messageTrả lời Agent (text trên màn hình — không TTS audio)
      {"type":"tts","state":"stop"}Kết thúc speaking ngay (không có TTS audio)

      5. .env mẫu

      STT_PROVIDER=whisper WHISPER_MODEL=medium TTS_PROVIDER=edge AGENT_PROVIDER=hermes HERMES_URL=http://127.0.0.1:8642

      Cổng máy chủ

      HTTP + WebSocket dùng chung một port. Đổi port sẽ ghi .env và restart gateway.

      TCP
      1024 – 65535
      LAN
      ESP32 và thiết bị khác trong LAN dùng IP này (không dùng localhost)

      Internet (domain công khai)

      Bật để ESP32 / trình duyệt ngoài nhà kết nối qua Cloudflare Tunnel. Hostname Named Tunnel không đổi. Sau khi áp dụng, app có thể tự cài cloudflared + tunnel.

      Nhập hostname → bấm Áp dụng → app tự mở hướng dẫn và chạy tunnel (chỉ cần đăng nhập Cloudflare một lần trong trình duyệt).

      Bảo mật WSS (LAN)

      Bật HTTPS/WSS cho ESP32 và thiết bị trong mạng LAN. Máy local (Tauri/trình duyệt) vẫn dùng ws://127.0.0.1.

      ESP32 có thể tự nhận cert qua hello WSS (lần đầu bỏ qua verify TLS, lưu tls_cert vào NVS). Hoặc copy cert bên dưới nếu firmware hỗ trợ nhập PEM. Cloudflare Tunnel: giữ tắt WSS này — Cloudflare cấp HTTPS/WSS. Gateway vẫn bind 0.0.0.0 để ESP32 vào được qua IP LAN.

      Loa Ai · Agent Bridge

      Nguồn gốc phần mềm

      Loa Ai Agent Bridge là cầu nối giọng nói do LoaAi.me phát triển, giúp thiết bị Loa Ai (ESP32, trình duyệt, ứng dụng desktop) giao tiếp bằng giọng nói với các agent AI trên máy tính của bạn.

      • STT — chuyển giọng nói thành văn bản (Whisper hoặc OpenAI).
      • Agent — xử lý lệnh qua OpenClaw, Hermes hoặc mock để thử nhanh.
      • TTS — đọc phản hồi bằng giọng nói (Edge, pyttsx3, …).
      • ESP32 — loa xiaozhi kết nối qua WebSocket Opus tới gateway local.

      Kết nối Agent

      Phần mềm được thiết kế để Loa Ai làm việc cùng backend agent bạn đã cài sẵn — không thay thế OpenClaw hay Hermes, mà là lớp trung gian nhận audio, gọi agent, rồi trả lời bằng TTS.
